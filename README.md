# Seed OS

## what is it?
This is a rudimentary kernel, built from scratch. This is an unfinished project meant to run on x86_64

## what is the goal?
I know this is gonna be a multi-month project so these are the following goals in the order that i will be attempting them.

* print "hello world" to the screen through the kernel
* show output through a serial port 
* having a reliable interrupt handling system
